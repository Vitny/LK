# Функционал и стили страниц

### Все страницы

- состояния и эффекты наведения для интерактивных элементов и кнопок;
- при ширине экрана менее 1000px боковая панель скрывается и отображается кнопка для её открытия. Панель выезжает слева; закрывается по клику вне панели или по кнопке закрытия;
- переключение активного пациента в верхней панели.

### Мои записи

- переключение между предстоящими и прошедшими записями с отображением соответствующего списка;
- всплывающий tooltip при наведении на иконку `info` у подтверждённой записи.

### Профиль

- всплывающий tooltip при наведении на иконку `info` в заголовке страницы.

### Страницы записи

- переключение состояний при выборе варианта записи и активация кнопки «Продолжить» после выбора;
- переключение недель в календаре вперёд и назад;
- переключение состояний при выборе времени записи и активация кнопки «Продолжить» после выбора;
- на странице подтверждения записи — всплывающий tooltip при наведении на иконку `info` у типа записи.
