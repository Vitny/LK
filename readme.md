# Функционал и стили страниц

### Все страницы

- эффекты наведения и состояния кнопок
- при размере экрана меньше 1000px скрывается боковая панель и отображается кнопка для раскрытия, панель выезжает с левой части экрана. Клик вне зоны панели или по кнопке закрытия скрывает панель
- переключение активного пациента в верхней панели

### Мои записи

- переключение по кнопке между предстоящими или прошедшими записями и скрытие соответсвующих записей
- всплывающий tooltip при наведении на иконку info у подверждённой записи

### Профиль

- всплывающий tooltip при наведении на иконку info у заголовка страницы

### Cтраницы записи

- переключение состояний при наажтии кнопок выбора + активация кнопки "Продолжить"
- переключение недели в календаре - на неделю вперёд и обратно
- переключение состояний при выборе времени записи + активация кнопки "Продолжить"
- на странице подтверждения записи всплывающий tooltip при наведении на иконку info у типа записи
